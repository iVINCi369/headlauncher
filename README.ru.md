# HeadLauncher

**Свой Tailscale (headscale) с управлением из Telegram.** Одна команда ставит всё; дальше — только кнопки.

```
curl -fsSL https://raw.githubusercontent.com/iVINCi369/headlauncher/main/install.sh | sudo bash
```

Установщик спрашивает три вещи — домен, токен бота из [@BotFather](https://t.me/BotFather) и (по желанию) твой Telegram ID, — поднимает `headscale + caddy + бот` через Docker Compose, получает TLS-сертификат и печатает одноразовую ссылку. Нажал — стал администратором и получил **первый ключ подключения с QR** прямо в чат.

## Что умеет

- **Панель (Mini App)** — устройства (имя, теги, маршруты, exit-node, разлогин, удаление), pre-auth ключи с QR, пользователи, статус.
- **Выдать доступ одним касанием** — кнопка *Скинуть* открывает выбор чата с готовой инструкцией для нового человека.
- **Регистрация по ссылке** — вставь `/register/…` из `tailscale up` в чат.
- **Exit-node** — кнопка для хостов, куда бот ходит по SSH (`EXIT_HOSTS`); теги `exit`/`router` автоодобряют маршруты для остальных.
- **Файлы** — документ боту → тикет [sendme](https://github.com/n0-computer/sendme) (iroh) + QR; тикет боту → бот скачает файл. P2P, без ограничений кроме 50 МБ на доставку в чат.
- **Обновления** — кнопка *Обновления*: headscale (с бэкапом базы и откатом) и сам бот.
- **Встроенный DERP** — работает за строгим NAT без публичных релеев.
- Русский / английский по языку Telegram (`/lang` переключает).

## Требования

Linux-сервер с публичным IPv4, открытые порты 80/443 (TCP) и 3478 (UDP), домен, указывающий на него. 1 ГБ RAM достаточно.

## Устройство

```
/opt/headlauncher
├── .env                  # настройки (chmod 600)
├── docker-compose.yml
├── caddy/Caddyfile
├── headscale/            # шаблон конфига и ACL по умолчанию
├── bot/                  # Telegram-бот (Python, aiogram + FastAPI)
└── data/                 # база и ключи headscale, сертификаты, состояние бота, бэкапы
```

Логи: `docker compose -f /opt/headlauncher/docker-compose.yml logs -f bot` · повторный запуск `install.sh` обновляет код и контейнеры.

## Безопасность

Панель принимает только запросы, подписанные Telegram (HMAC `initData` токеном бота) от админских ID; каждый обработчик бота проверяет отправителя. API-ключ headscale не покидает сервер.
